Module 2 · The internet

האינטרנט הוא רשת של מחשבים — לקוחות ושרתים

כל מחשב יכול להיות לקוח, שרת — או שניהם.

שחקו עם המפה כדי להבין איך זה עובד: בחרו אפליקציה, ועברו עם העכבר על כל מחשב.

Module 2 · HTTP

כל סרטון שאתם רואים הוא בקשות ותשובות

הסרטון הזה לא "יושב" אצלכם במחשב. הנגן מבקש אותו חתיכה-חתיכה, והשרת עונה — עשרות פעמים בזמן שאתם צופים.

לחצו Play, ותראו את זה קורה באמת.

network מחכה שתלחצו Play
🏆 הסרטון הכי נצפה ביוטיוב אי פעםBaby Shark Dance · Pinkfong

כל שורה ביומן היא בקשה אמיתית. הנגן מוריד את הסרטון בחתיכות, קצת לפני שצריך, בבקשות POST לשרת הווידאו — לכן היומן ממשיך לזוז כל עוד הסרטון רץ. הדפדפן לא נותן לדף לקרוא בקשות של אתר אחר, אז השורות כאן מגיעות מהנגן עצמו; כדי לראות את כולן: F12 ← Network ← videoplayback.

Module 2 · HTTP

HTTP — מה שגורם לכל זה לקרות

כל חץ שראיתם במפה, וכל חתיכת וידאו שהגיעה עכשיו, היא הודעה באותה שפה: HTTP. הלקוח שולח בקשה, השרת מחזיר תשובה — ובכל אחת יש הרבה יותר ממה שרואים.

עברו עם העכבר על כל חלק בהודעה כדי לראות מה הוא אומר.

Module 2 · Client ⇄ Server

סימולטור HTTP: בנו בקשה, וראו מה השרת עונה
