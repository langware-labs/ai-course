# הרצאה 2 — יסודות הווב

היום לומדים את שני הרעיונות שכל אתר ואפליקציה בנויים מהם: **איך בנוי דף אינטרנט** (HTML), ו**איך הדף מדבר עם שרת** (שרת ולקוח). פותחים את `slides/index.html` ועוברים בין השלבים עם הסרגל למעלה.

## מבנה ההרצאה

| שלב | מה יש בו |
|---|---|
| 1. היום | מה עושים בהרצאה ומה תדעו בסוף |
| 2. איך עובדים | איך עובדים עם השיעורים ועם נטי |
| 3. מבוא ל-HTML | HTML, CSS ו-JavaScript — מי אחראי על מה |
| 4. מודול HTML | "Handmade Web" — 10 שיעורים |
| 5. רשת האינטרנט | מפה אינטראקטיבית: איך YouTube, WhatsApp, Waze, Instagram ו-Roblox עובדים — מי לקוח, מי שרת, ומי גם וגם |
| 6. סרטון חי | נגן YouTube אמיתי ולידו לוח תנועה: רואים את הסרטון מגיע חתיכה-חתיכה בזמן שהוא מנגן |
| 7. HTTP | איך נראות בקשה ותשובה: GET, POST ו-WebSocket, חלק אחרי חלק |
| 8. סימולטור HTTP | מיני-פוסטמן: בונים בקשה (GET/POST/PUT/DELETE, כתובת וגוף JSON), שולחים, ורואים מה השרת קיבל ומה החזיר |
| 9. תרגילי קריאה | שבעה תרגילי **קריאה**: שולחים בקשה, קוראים את התשובה, ועונים ממנה — בלי לכתוב קוד |

## מודול HTML — מה לומדים

| שיעורים | נושא | מה תדעו בסוף |
|---|---|---|
| 1–4 | HTML | תגיות, כותרות והדגשות, קישורים ותמונות, רשימות וטבלאות |
| 5–7 | CSS | צבעים ופונטים, מודל הקופסה, סידור עם Flexbox |
| 8–10 | JavaScript | משתנים, שינוי הדף בתגובה ללחיצה, תנאים |

## איך עובדים

1. בכל שיעור יש הסבר קצר מצד שמאל, ורשימת משימות תחת **Your task**.
2. כותבים קוד בחלון הכהה. החלון הלבן מתחתיו מראה מה הדפדפן מציג.
3. כשחושבים שסיימתם, לוחצים **Check my work**. משימה שעברה מסומנת ב-✓, משימה שחסרה ב-×.
4. כשכל המשימות עברו, עוברים לשיעור הבא עם **next →**. ההתקדמות נשמרת.

## נטי, המלווה שלכם

כשפותחים את הקורס ב-Flowpad, נטי פותחת את ההרצאה ויושבת לידכם בצ'אט.

- **נטי רואה את המסך שלכם**: באיזה שלב ושיעור אתם, מה כתבתם, מה עבר בבדיקה — ובסימולטור גם איזו בקשה שלחתם ומה השרת ענה.
- **איך מבקשים עזרה**: כותבים לה בצ'אט, או כותבים שאלה בתיבת **Ask Neti** בתוך השיעור ולוחצים על הכפתור. אפשר גם להשאיר את התיבה ריקה ופשוט לבקש רמז.
- **נטי שמה לב בעצמה**: כשסיימתם שיעור, כשבדיקה נכשלה פעמיים ברצף, או כשאתם תקועים כמה דקות — היא תכתוב לכם.
- **נטי לא נותנת פתרונות**. היא נותנת רמזים, שלב אחרי שלב, עד שתגיעו לבד. ככה לומדים באמת.
